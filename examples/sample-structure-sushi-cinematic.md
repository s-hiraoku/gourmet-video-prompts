# 構成案の例（シネマティック／寿司・15秒）

メインコピーで魅せて、途中は映像に語らせるスタイル。ナラティブ（`sample-structure-sushi.md`）と混ぜて使ってもOK。

・0-2秒【フック】: 艶やかな赤酢のまぐろの握りを持ち上げるカット ＋ メインコピー「明石で出逢う、端正な江戸前」
・3-6秒【展開】: アワビなどが並ぶ立体的なお造りの盛り合わせ から、愛らしい蛸の醤油差しが鎮座する卓上 へのパン映像。
・7-10秒【場面転換】: （動画があれば）女性板前がカウンター越しにテンポよく握る、洗練された手元の所作へアングルを切り替える。なければ、美しい絵柄の器に乗った穴子 や雲丹 の寄りカットをテンポよく繋ぐ。
・11-13秒【補足】: スプーンで美しく供されるいくら と、明石ウィスキーのグラス を並べ、コースの余韻を伝える。
・14-15秒【CTA】: 「鮨の概念が変わる夜」というテキストとともに、右下の保存マークをタップするアニメーション。
・BGM提案: 凛としたカウンターの空気に馴染む、ピアノメインの静かなコンテンポラリー・ジャズ。

## Claude の読み取り方
| 構成案 | 完成動画での秒数 | 使う機能 |
|---|---|---|
| 0-2秒 フック | 0.0〜3.0 | 持ち上げる瞬間の動画 ＋ `title`（縦書き） |
| 3-6秒 展開 | 3.0〜7.0 | 盛り合わせ→卓上が1本に映る動画、または写真に `pan_*` |
| 7-10秒 場面転換 | 7.0〜11.0 | 握る所作の動画。なければ穴子・雲丹の寄りを `cut` で3つ |
| 11-13秒 補足 | 11.0〜13.0 | いくら と グラス を画面分割（`items`） |
| 14-15秒 CTA | 13.0〜15.0 | `title`「鮨の概念が変わる夜」＋ `save_tap`（CTA を2秒にするため補足から1秒もらう） |

この構成案から作る plan.json の例: `examples/sample-plan-cinematic.json`（素材名は仮）
