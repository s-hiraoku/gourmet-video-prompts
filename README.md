# gourmet-video-prompts

Instagramのグルメリール（縦型ショート動画）を**AIに設計させて、自動で動画まで完成させる**ためのセットです。
動画の長さは**デフォルト15秒**です（入力テンプレートで変更可）。

素材（動画・写真 複数）＋店舗・料理情報＋テロップ情報（動画に入れる文字）＋キャプション案を渡すと、AIが以下を作ります。

- 素材の分析（使う/使わない素材と秒数）
- 秒単位の編集台本（テロップ・演出・効果音）
- 編集アプリにそのまま打ち込めるテロップ一覧
- カバー（サムネ）案 / BGMの提案
- キャプション（店舗情報ブロック付き）とハッシュタグ
- A/Bテスト用の別パターン
- **自動編集用データ（plan.json）** → スクリプトで縦型mp4を自動作成

## 全体の流れ

```
素材（動画・写真）・店舗/料理情報・テロップ情報
        │
        ▼
AI（プロンプト）→ 台本・キャプション・plan.json
        │
        ▼
scripts/make_reel.py → output/reel.mp4（完成動画）
        │
        ▼
インスタに投稿（キャプションを貼る・音楽はアプリで追加）
```

## はじめに1回だけやること（準備）

1. Python 3 をインストール（Windows は [python.org](https://www.python.org/downloads/) から）
2. このフォルダでターミナルを開き、次を実行

```bash
pip install -r requirements.txt
```

これで動画編集ツール（ffmpeg）も一緒に入ります。

## 毎回の使い方

1. **素材を `materials` フォルダに入れる**
   名前は動画なら `v1.mp4`, `v2.mov`…、写真なら `p1.jpg`, `p2.png`… のようにする
   （iPhone の HEIC 写真は JPEG に変換してから入れてください）
2. **AIに依頼する**
   - `prompts/instagram-gourmet-reel.md` の「プロンプト本文」をコピーしてAIに貼る
   - その下に `templates/input-template.md` を埋めたものを貼る
   - 動画・写真ファイルを添付して送信
3. **AIの回答の最後にある「10. 自動編集用データ」を `plan.json` という名前で保存**（このフォルダの一番上に）
   ` ```json ` の囲みごとコピーしてもそのまま読めます
4. **動画を作る**

   ```bash
   python3 scripts/make_reel.py plan.json
   ```

   → `output/reel.mp4` ができます（Windows は `python` で実行）
5. **インスタに投稿**：AIが作ったキャプションとハッシュタグを貼り付け。インスタ内の曲を使うなら投稿画面で追加

### うまくいかないとき

- 動画を作る前に中身だけ確認：`python3 scripts/make_reel.py plan.json --check`
- 「秒数が一致していません」と出たら、AIに「clips の合計を15秒ちょうどにして plan.json を出し直して」と頼む
- テロップの文字が出ない・化ける：`--font フォントファイルのパス` で日本語フォントを指定
- 素材フォルダや出力先を変える：`--materials フォルダ` / `--out 出力ファイル.mp4`

## 自動で作れること・作れないこと

| できる | できない（投稿時にアプリで追加） |
|---|---|
| 縦型 1080×1920 への切り抜き・並べ替え | インスタ内の音源（著作権のある曲） |
| 写真のゆっくりズーム・スライド | テロップのアニメーション・流行りのエフェクト |
| テロップ（5種類のスタイル・上/中央/下） | ナレーション音声 |
| 原音を残す/消す、BGMファイルの合成 | |

## ファイル構成

| ファイル | 内容 |
|---|---|
| `prompts/instagram-gourmet-reel.md` | メインのプロンプト |
| `templates/input-template.md` | 毎回埋める入力テンプレート |
| `scripts/make_reel.py` | plan.json から動画を自動で作るスクリプト |
| `examples/sample-input.md` | 入力の記入例 |
| `examples/sample-plan.json` | plan.json の例（記入例に対応） |
| `materials/` | 素材を入れるフォルダ（Gitには入りません） |
| `output/` | 完成した動画が出るフォルダ（Gitには入りません） |
